# v1.0 Knowledge Manifest

The live GPT uses nine reference files. Behavioral rules, task routing, integrity boundaries, and output requirements remain in the Instructions field.

| Knowledge file | Purpose |
| --- | --- |
| `media-tech-recruiter-company-scorecards-interview-bank.md` | Recruiter lenses, company scorecards, interview questions, and answer-pressure tests for enterprise sales, strategic accounts, GTM, and startup roles. |
| `senior-commercial-positioning-knowledge-file.md` | Senior commercial positioning, resume and LinkedIn guidance, builder-versus-operator framing, and credible translation into AI roles. |
| `recruiter-outreach-framing-knowledge-file.md` | Recruiter outreach framing, practical rewrite rules, and concise follow-up guidance. |
| `advanced-recruiter-archetypes-scorecards.md` | Role archetypes, candidate scorecards, negotiation posture, and case-study evaluation. v1.0 removes canned enthusiasm and requires user-supplied sentiment. |
| `job-description-deconstruction-playbook.md` | Job-description deconstruction, role archetype classification, hidden screens, and proof requirements. |
| `resume-routing-and-positioning-matrix.md` | Routing guidance for choosing the right resume and positioning angle by role type. |
| `openai-commercial-role-prep.md` | Reference material for commercial-role preparation at OpenAI. Current company and role facts must still be verified through live research. |
| `senior-commercial-proof-story-bank.md` | Proof-story selection and development for revenue, accounts, leadership, launches, setbacks, and cross-functional work. |
| `gtm-case-study-and-30-60-90-rubric.md` | Rubrics for GTM cases, account plans, executive presentations, and 30/60/90 plans. |

## Deliberate exclusions

The release does not include personal resumes, candidate notes, confidential compensation files, employer documents, interview transcripts, or private job-search materials.

`senior-commercial-comp-negotiation-playbook.md` was removed before v1.0. Its canned message examples introduced unsupported enthusiasm into otherwise evidence-safe negotiation drafts. The useful compensation logic is covered by the Instructions and remaining reference files.

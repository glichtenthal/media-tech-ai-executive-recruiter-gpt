# Feedback & Help

Media & Tech Exec Recruiter is a free, independent project. Use the form to report a problem, suggest an improvement, ask for help using the plugin, or make a privacy request.

[Open the Feedback & Help form](https://tally.so/r/9N75ZQ)

For a problem report, include the OpenAI product you were using, the plugin version if you know it, and what you expected to happen. Use a short fictional or redacted example. Leave out resumes, offer letters, private chat transcripts, and confidential work information.

Submissions are reviewed as time allows. Include an email address only if you'd like a reply or need one to complete your request. I use feedback to guide updates.

See the [privacy policy](PRIVACY.md) for how submissions are handled, including the **60-day retention rule after resolution**. See the [project overview](README.md) for product history and availability.
